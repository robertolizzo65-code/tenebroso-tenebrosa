# Tenebroso & Tenebrosa

Sito personale dark/gotico per foto, video, song e storie horror.

## Pubblicazione con GitHub Pages
1. Carica `index.html`, `style.css` e `script.js` nella root del repository.
2. Vai su **Settings → Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Branch: `main`, cartella: `/ (root)`.
5. Salva.

Il sito sarà disponibile all'indirizzo:
`https://robertolizzo65-code.github.io/tenebroso-tenebrosa/`

## Personalizzazione
Sostituisci i riquadri della galleria con le vostre foto e aggiungi i link dei video YouTube e delle song.
